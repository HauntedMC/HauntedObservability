# Support

## Where to get help

- Setup and usage help: https://www.hauntedmc.nl/support
- Bug reports: GitHub Issues using the bug template
- Feature proposals: GitHub Issues using the feature template
- Security concerns: [SECURITY.md](SECURITY.md)

## Before opening an issue

Please include:

- HauntedObservability version
- Java version
- runtime (`Paper`, `Velocity`, or standalone test/application use)
- FeatureFramework/DataProvider/DataRegistry versions when relevant
- OpenTelemetry Collector version and relevant sanitized configuration
- concise reproduction steps
- relevant logs or exported telemetry examples

Never include passwords, GitHub tokens, OTLP credentials, database credentials, player identifiers, SQL/query text, Redis keys/payloads, or other production secrets. Redact private hostnames and IPs unless they are essential to the problem.

Support and triage are best-effort and prioritized by impact and reproducibility.
